# Stage-level climate risk in marine invertebrates

This repository contains the analysis-ready effect-size data, statistical scripts, result tables and figure source data for the manuscript `Estimands and evidence structure reshape stage-level climate risk in marine invertebrates`.

## Analysis structure

- Signed directional log response ratios
- Conservatively endpoint-aligned performance responses
- Null-calibrated departure from reference conditions
- Study-held-out generalizability evaluation

The prediction analysis evaluates transferability and is not treated as a fourth estimand.

## Reproduction

See [RUN_REPRODUCTION.md](RUN_REPRODUCTION.md) for software requirements and commands. The R workflow starts from `data/processed/analysis_ready_model_dataset.csv`; the Fig. 1 script uses archived figure source tables; the reference-deviation and prediction workflow uses the same analysis-ready dataset.

## Repository contents

- `R/`: analysis and figure scripts
- `data/processed/`: analysis-ready data and result tables
- `data/source_data/`: figure-level source tables
- `figures/`: Illustrator-editable PDF and SVG vector source files
- Journal-upload TIFF files are kept separately in the submission package
- `analysis_logs/`: reproducibility logs generated by the analysis scripts

Questions about data provenance, coding or analysis should be directed to the corresponding author listed in the manuscript.
